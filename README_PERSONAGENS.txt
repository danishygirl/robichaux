COVEN — PÁGINA PERSONAGENS + FILTROS

Este pacote é parte de um SITE NOVO criado do zero. Não depende dos sites anteriores.

A página Personagens é totalmente dinâmica:
- adicione quantos personagens quiser em public/personagens-data.js;
- cada personagem cria sozinho um cartão e seu dossiê;
- os filtros também são editáveis em public/personagens-data.js;
- o grid aumenta verticalmente e passa a rolar normalmente quando houver muitos registros.
